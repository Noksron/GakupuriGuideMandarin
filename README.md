# 学院祭的王子们 · 青学攻略

静态页面，无框架、无构建，直接丢 GitHub Pages 就能用。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面本体（结构 + 样式 + 逻辑都在这一个文件里） |
| `data.js` | 攻略数据，由 Excel 转换生成 |
| `convert.py` | Excel → `data.js` 的转换脚本 |

## 更新攻略

改 Excel，然后重新生成数据：

```bash
pip install openpyxl
python3 convert.py 青学.xlsx 氷帝.xlsx ルドルフ.xlsx 不动峰.xlsx -o data.js
```

一个学院一个 Excel 文件，文件名里带「青学 / 氷帝 / ルドルフ / 不动峰 / 山吹 / 立海」等关键字就会自动归到对应学院。新学院在 `convert.py` 顶部的 `SCHOOLS` 里加一行即可。

脚本会顺带报出「选择列没填」的行，方便查漏。

`index.html` 不用动。

## Excel 格式约定

每个角色一个工作表：

- `B2` 角色名，`C3` 特殊话题，`J3` 嫉妒程度
- 第 5 行表头，第 6 行起是数据：`B` 日期 `C` 时间 `D` 类别 `E` 场所 `F` 选择 `G` 备注 `H` 获取
- `A` 列填 `*` 表示该回合有差分
- `F` 列填 `-` 表示本回合没有选项；留空则视为待补充
- `C3` 里 `丨` 之后的内容会单独显示为一条提示（如吧台选颜色 +1）
- `J8:V11` 好感度区间 × 话题加成表，区间分隔符 `—` `–` `~` `～` 都认
- `J13` 起可放一张备用路线小表（如海堂的「制服 CG 回收」）

## 部署到 GitHub Pages

1. 新建 public 仓库，把这三个文件放在根目录
2. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`
3. 等一两分钟，访问 `https://用户名.github.io/仓库名/`

数据写在 `data.js` 里而不是 `data.json`，所以本地双击 `index.html` 也能直接看（`fetch` 在 `file://` 下会被浏览器拦掉）。

## 进度勾选

每条事件左侧的方框可勾选，进度存在浏览器 `localStorage`（键名 `gakuensai.progress.v1`），刷新和关机都不会丢，但换设备或换浏览器不会同步。无痕模式下会自动退回内存存储，页面底部会提示。侧栏「清除全部进度」可一键重置。

## 还能加的

- CG 图鉴：`获取` 列已经标出了每张 CG 的入手点，补上图片路径就能做成图鉴页
- 结局条件：Excel 里还没有这部分，加一列或一张小表即可
