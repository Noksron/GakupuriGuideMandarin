# 学院祭的王子们 · 全角色攻略

《网球王子 · 学园祭的王子们》的全角色攻略整理，按会期 **8/22 – 9/1** 逐日列出每个回合该去哪、选什么、能拿到什么，目标是**全 CG 收集**。

线上地址：<https://noksron.github.io/GakupuriGuideMandarin/>

---

## 怎么用

**首页**是八所学院的总览，每张卡片列出该校角色和各自的整理情况，点名字直接进入。点页头的 logo 或左侧竖栏第一行的「首页」可以随时回来。

**左侧竖栏**用来换角色。鼠标移上去会展开（手机上点一下左边那条色带），点学院展开该校名单，再点角色即可。

**筛选**在角色名下方，可以只看 CG、只看小游戏、只看分歧点，或者只看还没勾的。

**勾选框**在每条事件左边，点一下标记完成。进度存在你自己浏览器里，我这边看不到，换设备或换浏览器也不会同步；无痕模式下只在本次访问内有效，页面底部会提示。左侧竖栏底部的「清除全部进度」可以一键重置。

## 看懂那些标签

| 标签 | 含义 |
| --- | --- |
| 晨 / 昼 / 夕 / 夜 / 全天 | 该回合的时段 |
| 对话 / 查看 / 约会 / 自动发生 | 行动类别 |
| 黄绿色实色 | 这一步能拿到 CG |
| 青绿色实色 | 这一步能拿到话题（对话用的道具） |
| 红色「分歧 · 先存档」 | 这一回合有差分，选之前建议先存档 |
| 描边「小游戏」 | 这一步会进小游戏 |
| 虚线「日期不固定」 | 触发日期不固定，写的日子仅作参考 |

引号「」里的是**要选的选项原文**，`→` 表示同一回合里接连出现的多个选项，按顺序选。灰色小字是补充说明。

---

## 分歧点怎么读

带红色「分歧」标签的那一条是**主选择**，它下面缩进的灰框里是**另一条分支**，两者二选一。

两条分支各算一格进度、各有自己的勾选框——因为全 CG 收集要求两边都拿，所以进度满格意味着两条都走过。建议在分歧点前存档，先走一条，回头读档再走另一条。

---

## 关于日期

游戏内用的是虚拟日历：会期第一天 **8/22 固定是周一**，往后顺推，和现实中的任何一年都对不上。页面上显示的周几按游戏内的算。

---

## 好感度加成表

每个角色页面底部可以展开「好感度区间 × 普通话题加成」。数值越高的话题在当前好感度区间越值得聊；好感度 10 以下时所有话题一律 +1。

---

## 「待补充」是什么意思

标着「待补充」的角色是名单里有、但还没整理完的。八所学院 38 位角色的框架都已经搭好，会陆续往里填。
