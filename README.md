# 学院祭的王子们 · 全角色攻略

静态页面，无框架、无构建，直接丢 GitHub Pages 就能用。
线上地址：<https://noksron.github.io/GakupuriGuideMandarin/>

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面本体（结构 + 样式 + 逻辑都在这一个文件里） |
| `data.js` | 攻略数据，由 Excel 转换生成 |
| `convert.py` | Excel → `data.js` 的转换脚本，全学院名单也在里面 |
| `make_assets.py` | 立绘原图 → 侧栏头像 + 正文立绘 |
| `assets/crest/` | 立绘原图（素材，页面不直接引用） |
| `assets/avatar/` | 76×76 头像，侧栏用 |
| `assets/portrait/` | 300×360 立绘，角色页右上角用 |
| `assets/ui/logo.png` | 页头的游戏 logo |

## 更新攻略

改 Excel，然后重新生成数据：

```bash
pip install openpyxl
python3 convert.py 青学.xlsx 氷帝.xlsx ルドルフ.xlsx 不动峰.xlsx -o data.js
```

一个学院一个 Excel 文件，文件名里带「青学 / 氷帝 / ルドルフ / 不动峰 / 山吹 / 立海 / 六角 / 四天宝寺」等关键字就会自动归到对应学院。

`index.html` 不用动。

### 全学院名单（`ROSTER`）

`convert.py` 顶部的 `ROSTER` 是**唯一的真相来源**：学院顺序、分组、学院色、每个学院有谁，全在这里。

不管这次丢了几个 Excel 进去，生成的 `data.js` 永远是完整的 8 校 38 人；还没整理的角色会带上 `todo`，在站上显示成「待补充」，侧栏压暗但仍可点开。补一个 Excel 亮一个，不会把占位冲掉。

⚠️ Excel 工作表 `B2` 的角色名要和 `ROSTER` 里写的一致。写法不同不会报错，但那个角色会被当成新人单独挂在学院末尾，终端会打一行 `! 名单里没有…` 提醒。

### 表格之外的补充说明（`EXTRA_TIPS`）

有些提示不适合塞进 Excel（比如「奖励CG为「学院祭扣杀BINGO」中概率获得」）。写进 `convert.py` 的 `EXTRA_TIPS`，按 `"学院·角色"` 挂，会显示在角色名下面，重跑脚本也不会丢：

```python
EXTRA_TIPS = {
    "冰帝学园·迹部景吾": ["奖励CG为「学院祭扣杀BINGO」中概率获得"],
}
```

一个角色可以挂多条，列表里多写几个字符串即可。

## 生成头像和立绘

把角色立绘原图（透明底 PNG）放进 `assets/crest/`，文件名用角色名，然后：

```bash
pip install pillow numpy
python3 make_assets.py
```

脚本会靠肤色自动找脸，裁出 76×76 的侧栏头像，再按头部位置对齐生成 300×360 的统一画框立绘（下缘柔化，融进页面底色）。文件名去掉空格后能和 `ROSTER` 对上就行；繁简、日文名对不上的，在 `make_assets.py` 的 `ALIAS` 里点名。

## Excel 格式约定

每个角色一个工作表：

- `B2` 角色名，`C3` 特殊话题，`J3` 嫉妒程度
- 第 5 行表头，第 6 行起是数据：`B` 日期 `C` 时间 `D` 类别 `E` 场所 `F` 选择 `G` 备注 `H` 获取
- `A` 列填 `*` 表示该回合是分歧点
- `F` 列填 `-` 表示本回合没有选项；留空则视为待补充
- `C3` 里 `丨` 之后的内容会单独显示为一条提示（如吧台选颜色 +1）
- `J8:V11` 好感度区间 × 话题加成表，区间分隔符 `—` `–` `~` `～` 都认
- `J13` 起可放一张备用路线小表（如海堂的「制服 CG 回收」）

### 分歧点怎么排

打了 `*` 的那一行是主选择；紧跟其后、**同日同时段同地点**的下一行会被当成它的另一条分支，在页面上收进主选择下方的灰框里，不再和主选择平级。

两条分支各算一格进度、各有勾选框——全 CG 收集要两条都走，所以满格是把两边都勾上。

### 获得物标签

「获取」栏里带 `CG` 的显示成黄绿实色标签，带「话题」的显示成青绿实色标签；`特训的话题、剧情CG` 这种会自动拆成两个标签（`28日、31日私服CG` 不会被误拆）。

「备注」栏保守一些，只有整段就是「XX的话题」才升级成标签，其余留作灰色说明文字。

## 日期

游戏内是虚拟日历：会期第一天 `8/22` 固定为周一往后顺推，不跟任何真实年份。锚点在 `index.html` 的 `DAY0` / `DAY0_WEEK`。

## 部署到 GitHub Pages

Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，等一两分钟即可。

数据写在 `data.js` 里而不是 `data.json`，所以本地双击 `index.html` 也能直接看（`fetch` 在 `file://` 下会被浏览器拦掉）。

## 进度勾选

每条事件左侧的方框可勾选，进度存在浏览器 `localStorage`（键名 `gakuensai.progress.v1`），刷新和关机都不会丢，但换设备或换浏览器不会同步。无痕模式下会自动退回内存存储，页面底部会提示。侧栏「清除全部进度」可一键重置。

## 还能加的

- CG 图鉴：`获取` 列已经标出了每张 CG 的入手点，补上图片路径就能做成图鉴页
- 结局条件：Excel 里还没有这部分，加一列或一张小表即可
- 页头的背景图 / 主视觉：`assets/crest/` 里有原图，压缩后可以用起来
